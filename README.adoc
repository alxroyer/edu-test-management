=== Edition et visualisation dans VS Code

Pour le cours :

* Installer l'extension link:https://marketplace.visualstudio.com/items?itemName=asciidoctor.asciidoctor-vscode[AsciiDoc] par asciidoctor.
* Ouvrir le fichier `Test management.adoc`.
* Clic droit sur l'onglet du fichier > "Open Preview"

Pour les slides, à partir de VS Code :

* Installer l'extension link:https://marketplace.visualstudio.com/items?itemName=flobilosaurus.vscode-asciidoc-slides[AsciiDoc Slides] par flobilosaurus.
* Ouvrir le fichier `Test management - slides.adoc`.
* F1 > "AsciiDoc Slides: Show Slides Preview Beside"



=== Générer les sorties HTML et PDF

Pour l'export PDF du cours :

* Ouvrir le fichier `Test management.adoc` dans VS Code.
* F1 > "AsciiDoc: Export document as PDF".
* Sélectionner le fichier cible `Test management.pdf`.

Pour la production HTML des slides,
à partir de répertoire principal du dépôt :

[source, bash]
$ npm ci
$ ./scripts/generate-slides.sh

Pour l'export PDF des slides :

* Ouvrir le fichier `Test management - slides.html` généré précédemment
  dans un navigateur.
* Ajouter `?print-pdf` après l'extension `.html` dans l'URL.
* File > Print > "Save to PDF"
