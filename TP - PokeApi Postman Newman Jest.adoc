== Objectifs

* Découvrir l'API PokeAPI et ses endpoints.
* Créer une collection Postman pour tester manuellement les endpoints.
* Automatiser les tests avec Newman.
* Écrire des tests unitaires avec Jest pour valider les réponses de l'API.


== Prérequis

* Un compte Postman (gratuit) : https://www.postman.com/
* Node.js installé (pour Newman et Jest).
* Un éditeur de code (VS Code, Sublime Text, etc.).


== 1. Découverte de PokeAPI

Durée : 15 min

* Consigne : Explorez la documentation de PokeAPI et identifiez 3 endpoints intéressants (ex: /pokemon/{id}, /berry/{id}, /type/{id}).
* Ressources :

** Documentation officielle de PokeAPI : https://pokeapi.co/docs/v2
** Exemple d'URL : https://pokeapi.co/api/v2/pokemon/1 (Bulbizarre)
** Dépôt github : https://github.com/PokeAPI/pokeapi/
** Contrat OpenApi : https://github.com/PokeAPI/pokeapi/blob/master/openapi.yml


== 2. Création d'une collection Postman

Durée : 30 min

Étapes :

1. Créez une nouvelle collection dans Postman nommée "PokeAPI Tests".

2. Ajoutez 3 requêtes (GET) pour les endpoints choisis.

3. Pour chaque requête :

  * Ajoutez des tests pour vérifier :

    ** Le code de statut HTTP (200).
    ** La présence de champs spécifiques dans la réponse (ex: name, id, types).

  * Exemple de test Postman :
+
[source, javascript]
----
pm.test("Status code is 200", () => {
    pm.response.to.have.status(200);
});
pm.test("Response has a name", () => {
    const jsonData = pm.response.json();
    pm.expect(jsonData.name).to.be.a("string");
});
----

4. Exportez la collection au format JSON.
   Enregistrez le fichier sous le nom `PokeAPI_Tests.postman_collection.json`.


== 3. Automatisation avec Newman

Durée : 30 min

Étapes :

1. Installez Newman globalement :
+
[source, bash]
----
npm install --save-dev newman newman-reporter-html
----
+
TIP: Voir l'option `--legacy-peer-deps` au besoin. {fn-legacy-peer-deps}

2. Exécutez la collection depuis la ligne de commande :
+
[source, bash]
----
newman run PokeAPI_Tests.postman_collection.json
----

3. Générez un rapport HTML avec newman-reporter-html :
+
[source, bash]
----
newman run PokeAPI_Tests.postman_collection.json -r html --reporter-html-export report.html
----

4. Ouvrez le rapport report.html pour visualiser les résultats.


== 4. Tests unitaires avec Jest

Durée : 45 min

Étapes :

1. Initialisez un projet Node.js :
+
[source, bash]
----
npm init -y
npm install --save-dev axios jest
----
+
TIP: Voir l'option `--legacy-peer-deps` au besoin. {fn-legacy-peer-deps}

2. Créez un fichier pokeapi.test.js et écrivez des tests pour valider :

  * Le statut HTTP.
  * La structure des données retournées.
  * Exemple de test Jest :
+
[source, javascript]
----
const axios = require("axios");

test("GET /pokemon/1 returns Bulbasaur", async () => {
    const response = await axios.get("https://pokeapi.co/api/v2/pokemon/1");
    expect(response.status).toBe(200);
    expect(response.data.name).toBe("bulbasaur");
    expect(response.data.types).toBeInstanceOf(Array);
});
----

3. Exécutez les tests :
+
[source, bash]
----
npx jest
----


== 5. Intégration continue (Bonus)

Durée : 30 min

Étapes :

1. Crééz un dépôt npm sous github, contenant les éléments constitués lors des étapes précédentes :

  * S'assurer de l'installation des packages `newman`, `axios` et `jest`
    en mode `--save-dev`.
  * Ajouter les fichiers `PokeAPI_Tests.postman_collection.json`
    et `pokeapi.test.js` constitués précédemment.

2. Créez un fichier `.github/workflows/tests.yml` pour exécuter Newman et Jest via GitHub Actions.

3. Exemple de workflow :
+
[source, yaml]
----
name: PokeAPI Tests
on: [push]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - uses: actions/setup-node@v4
        with:
          node-version: "20"
      - run: npm install
      - run: newman run PokeAPI_Tests.postman_collection.json
      - run: npx jest
----
+
TIP: Voir l'option `--legacy-peer-deps` au besoin. {fn-legacy-peer-deps}
