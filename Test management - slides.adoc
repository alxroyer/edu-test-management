=== Interactions SUT

TIP: Pattern _wait-for / query_

* Aux interfaces du SUT
* Eviter les `sleep()` arbitraires de X secondes
* Préférer une gestion d'événements => _wait-for_
* Wait for what? => _query_ (OO Design)
